# أنا رمزك 🔒

موقع توعوي في الأمن السيبراني يساعد الناس على إنشاء رموز (كلمات مرور) قوية وفحص قوة رموزهم الحالية.

## المزايا

- **مولّد رموز قوية** باستخدام عشوائية التشفير في المتصفح (`crypto.getRandomValues`).
- **مستويات حماية جاهزة:** أساسي (12 حرفًا)، قوي (16)، فائق (24)، مع التحكم الكامل في الطول من 6 إلى 64.
- **اختيار المكونات:** حروف كبيرة، حروف صغيرة، أرقام، رموز خاصة، واستبعاد الحروف المتشابهة، ومنع التكرار المتتالي.
- **مقياس القوة:** ضعيف، متوسط، قوي، آمن جدًا، مع القوة بالبت وزمن الكسر التقريبي.
- **افحص رمزك:** يكشف الرموز الشائعة والتسلسلات والسنوات، ويقترح تحسينات ونسخة أقوى.
- **خصوصية كاملة:** كل شيء يعمل داخل المتصفح، ولا يُرسل أي رمز إلى أي خادم.
